# Checklist de recuperação do AdSense

- [ ] Cada URL do sitemap entrega HTML específico antes do JavaScript.
- [ ] Cada página indexável possui título, descrição, H1 e canonical próprios.
- [ ] Calculadoras indexáveis explicam fórmula, premissas, limitações e fontes.
- [ ] Artigos com números, leis ou segurança têm fontes primárias visíveis.
- [ ] Rotas de orçamento/estado e ferramentas ainda não revisadas usam `noindex, follow`.
- [ ] URL inexistente retorna HTTP 404, sem redirecionar para a home.
- [ ] Sitemap é gerado a partir do manifesto aprovado e não contém redirects.
- [ ] Anúncios e afiliados permanecem desativados durante a revisão.
- [ ] Consentimento LGPD/EEE bloqueia Analytics e AdSense até escolha explícita.
- [ ] Search Console confirma HTML renderizado e canonical após novo crawl.
